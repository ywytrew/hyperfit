# Changelog

## 0.1.0 — 2026-09-27

- Reimplemented named, modular hyperelastic energies and simultaneous stress/log-volume calibration.
- Added Ogden 1–3 terms, the exponential log-volume energy, bounded multi-start search, explicit tolerance/uncertainty modes and optional explored tradeoffs.
- Added FElupe mixed-element verification, repeated-eigenvalue-safe spectral derivatives and sampled acoustic tensors.
- Added local FastAPI jobs, explicit CSV/XLSX measure conversion, browser UI and reproducible result records.
- Added Chinese, English and Japanese UI localization, persistent language choice, and translated dynamic results and error summaries.
- Added full user manuals and deployment guides in all three languages, generated offline browser documents, Docker Compose and CI checks.
- Kept recovered legacy files untouched. No real-experiment reproduction, Abaqus compatibility certification or public hosting is claimed.
