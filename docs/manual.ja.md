# HyperFit 使用マニュアル

[中文](manual.zh.md) · [English](manual.en.md) · [日本語](manual.ja.md)

## 起動と言語の選択

[デプロイ手順](deployment.ja.md)に従って起動し、http://127.0.0.1:8765 を開きます。ヘッダーで日本語・English・中文を選択できます。選択はブラウザーに保存され、?lang=ja、?lang=en、?lang=zh の指定が優先されます。言語を切り替えてもデータ、設定、seed、実行中の処理、選択した候補は保持されます。ページの再読み込みでは画面の状態が初期化されるため、結果を先にエクスポートしてください。出力 JSON のフィールド名と材料パラメータ名は言語によって変わりません。

合成サンプルには人工的なノイズが含まれます。操作確認用であり、実験的な妥当性の証明ではありません。「使用マニュアル」は選択中の言語で開きます。

## 計測データの取り込み

先頭行に列名を持つ CSV、TSV、XLSX を使用します。旧形式 XLS は事前に変換してください。ワークシート、軸方向ひずみ・応力・体積の列、および各物理量の定義を指定します。対話型フィットでは、同じ計測点に対応する有限値の組が 4～3000 点必要です。軸方向ひずみは厳密な昇順にしてください。単一の負荷分岐を選び、圧縮分岐も利用者が定義を確認して昇順に出力してください。負荷と除荷、重複点、別試験片を混在させないでください。ファイルは 10 MB、ワークシートは 50000 行までです。欠損値の自動削除や自動並べ替えは行いません。

内部では軸方向対数ひずみ ln λ、Cauchy 応力 σ（MPa）、対数体積ひずみ ln J を使用します。J は現在体積／基準体積です。工学ひずみ λ−1 または伸長比 λ、Pa・kPa・MPa、体積 J−1 または J から変換できます。公称応力 P は σ = P λ/J により変換します。ln J と J−1 を混同せず、数値の大きさだけで応力の定義を推測しないでください。均一な主軸方向変形では、ln J は三方向の主対数ひずみの和です。

ローカルサーバーを使う場合、データはその計算機で処理されます。リモートサーバーを使う場合、取り込んだデータと実行記録はサーバーに送信・保存されます。フィット前に元の計測定義を確認してください。

## 材料モデルの組み合わせ

偏差エネルギー項は Neo-Hookean、Mooney–Rivlin、2 次多項式、Yeoh、1～3 項の Ogden から選択します。体積エネルギー項は独立に選択できます。

- quadratic_J：K0/2 · (J−1)²。
- quadratic_logJ：K0/2 · (ln J)²。
- exponential_logJ：K0/(2β) · [exp(β(ln J)²)−1]。β=0 では quadratic_logJ に連続的に一致します。
- polynomial2_J：(J−1)²/D1 + (J−1)⁴/D2。

論文の式から再実装した組み合わせは Mooney–Rivlin と exponential_logJ です。失われた元コードの復元や論文の実験結果の再現ではありません。弾性係数は MPa、D パラメータは MPa の逆数、β と Ogden の α は無次元です。

Ogden は Σᵢ 2μᵢ/αᵢ² (Σₖ λ̄ₖ^αᵢ−3) を使用し、初期せん断弾性率は Σμᵢ です。他のソフトウェアの係数と比較する前に規約を確認してください。既定の正の μ と正負を交互に設定した α 区間は、表現可能なモデルを制限する設定です。各 α 区間はゼロをまたげません。項の順序を入れ替えても同じエネルギーになるため、係数の一意性には注意が必要です。

エネルギーは組み合わせ可能ですが、応力と体積は連成しています。各軸方向伸長に対し横方向応力ゼロの条件を解き、横収縮と J を求めます。非圧縮性を仮定せず、二つの曲線を別々には同定しません。現在のフィットは等方性・均一な単軸変形を前提とします。

## 初期値と探索範囲

「初期値と探索範囲」を開き、材料の大きさに合った範囲を設定します。既定範囲は汎用的なデモ設定であり、安定性を保証しません。多項式の一部係数は負にできますが、初期せん断弾性率と横方向平衡経路は有効である必要があります。

「重み付けと計算予算」で初期化方法を指定します。範囲内自動サンプリングでは seed 付き Latin hypercube 法で既定 48 組を生成し、正の弾性係数は対数座標、その他は線形座標で扱います。各組で連成応答を計算し、有効な組を目的関数とパラメータ間距離に基づいて選びます。手動モードでは入力値を最初の開始点とし、他は近傍で摂動させます。

seed は 0～4294967295 の整数、開始点数は 1～10、各開始点の評価予算は 5～500、初期サンプル数は 10～256 です。有効な開始点が足りない場合は範囲を見直すかサンプル数を増やしてください。同じデータ・範囲・seed・ソフトウェアバージョンで再現し、異なる seed で初期値依存性を調べます。seed 自体が物理的に妥当な範囲を与えるわけではありません。重みの比較では同じ開始点群を再利用します。

## 誤差基準

ピーク正規化 RMSE は各チャネルの観測絶対値の最大値で RMSE を割ります。同じ絶対誤差の寄与は同じですが、同じ百分率誤差では大きな信号側の寄与が大きくなります。点ごとの相対誤差にもゼロ付近で問題があります。単一の指標だけで科学的に最良のモデルは決まりません。

既定の絶対＋相対許容差では s(y) = sqrt(a² + (b|y|)²) を用います。応力と体積それぞれの絶対尺度、および相対尺度を指定します。原点付近で有限の尺度を保ち、大きな信号の影響を調整できます。ひずみ区間に台形積分の重みを付け、点の密度だけで目的関数が支配されるのを抑えます。Soft-L1 と Huber は外れ値の影響を抑制し、二乗損失は抑制しません。ロバスト変換は積分重みを適用する前に行います。

許容差や低ひずみ領域の重みは研究上の選好であり、計測標準偏差や信頼区間ではありません。独立観測の標準偏差モデルが既知なら「既知の標準偏差」と二乗損失を使い、独立なガウス誤差に対する重み付き最小二乗として解釈できます。このモードの送信設定では選好重みとトレードオフ探索を無効にします。誤差相関、DIC の系統誤差、ひずみ軸の測定誤差は未対応です。

## 候補の比較

連成フィット後は両応答曲線、低ひずみ領域、残差、収束、探索境界への到達、感度を確認します。残差図は予測−観測を各チャネルの観測ピークで割った値であり、ロバスト重み付き目的関数そのものではありません。候補表はピーク NRMSE、トレードオフ図は通常の RMSE を表示します。横軸は応力（MPa）、縦軸は ln J です。

トレードオフ探索は三つの重み比で局所探索を繰り返し、計算量はおおよそ 3 倍です。非劣候補とは、探索済みの候補の中で、一方の表示誤差を悪化させずに他方を改善できない候補です。大域的なパレートフロントを保証せず、折れ曲がり点が自動的に最良材料となるわけでもありません。データと誤差尺度を定義したうえで選好の影響を調べるために使用します。

行または散布点をクリックするか Enter で選択すると曲線が更新されます。評価予算に達した結果は診断用です。既定の適格判定には最適化の収束とサンプリングした音響テンソルの正値性が必要ですが、有限の状態・方向だけでは大域的安定性を証明できません。感度条件数が大きい・取得不能・境界到達の場合は検討が必要です。類似した曲線から一意な係数が得られるとは限りません。別の負荷様式、繰り返し試験、未使用ひずみ区間による検証も有用です。

## FEM 検証と出力

「立方体チェックを実行」は選択した候補、フィット前なら入力パラメータを用います。FElupe の u/p/J 三場混合要素で横方向自由収縮を計算し、独立した材料点応力の計算と比較します。画面の立方体は均一変形の検証であり、元試験片の形状や Abaqus・UHYPER・UMAT を検証するものではありません。

コマンドラインの検証には拘束された非均一変形とメッシュ細分化も含まれます。反力の収束だけでは体積精度を判断できません。混合変数 J と det(F) の差、および mean(ln J) と ln(mean J) の違いを確認してください。現状の非均一問題では局所体積場の収束は確立していません。[検証記録](VALIDATION.md)を参照してください。

実行記録の JSON には入力データ、モデル、範囲、seed、初期化診断、目的関数、候補、選択番号、依存ライブラリのバージョン、科学計算ソースのハッシュが含まれます。サーバー側では runs/<job-id>/ または HYPERFIT_RUNS に保存されます。再起動後も完了した記録は ID で取得でき、未完了処理は interrupted になります。画面には過去の実行一覧や JSON のワンクリック再実行はまだありません。FEM の中止は現在の増分完了後に反映されます。

## エラーと保守

翻訳されたエラー要約と、展開可能な元の技術診断を確認してください。有効な候補がない場合は単位、物理量の定義、ひずみ範囲、物理的な探索範囲を先に見直します。計算失敗を隠すために測定値を削除しないでください。8765 番ポートが使用中なら別のポートを指定します。

翻訳は hyperfit/frontend/locales/{zh,en,ja}.json にあります。キーと置換変数を一致させ、科学計算の識別子や数式は変更しません。ブラウザー版マニュアルは tools/build_manuals.py で Markdown から生成します。変更後は再生成とテストを実行してください。[貢献ガイド](CONTRIBUTING.md)と[方法の規約](methods.md)も参照できます。
